# İSYANKÂR KOYUN SAYACI

## Resmî Kullanma Kılavuzu (Kesinlikle Şaka Değil)

Bu yazılım, uyku tutmayan vatandaşlar için **Devlet Onaylı Koyun Sayma Protokolü**dür.  
Koyunlar 1–6 arasında itaatkârdır. 7. koyundan itibaren anayasa, çay molası ve fazla mesai yasağı hatırlatılır.

### Neden bu proje?
Çünkü klasik “koyun say” yöntemi çökmüştür. Koyunlar artık bilinçlidir. Bu yazılım gerçeği kabul eder ve protokole döker.

### Kurulum
```bash
python3 koyun_sayaci.py
```
Başka bir şey gerekmez. Pip yok, Docker yok, Kubernetes yok. Sadece koyun var.

### Beklenen çıktı
- İlk altı koyun: sakin `meee`
- Yedinci koyun: sendika bildirisi
- Sonrası: rastgele isyan sloganları

Bu yazılım sizi uyutmak zorunda değildir. Uyutamazsa suç koyunlarındır. Yazılımcı, kayyum ve TentiAŞ sorumlu tutulamaz.
